# Daytona USA / Sega Racing Classic ROM symbols (from `d1a.exe`)

**651 records** of `{u32 guest_addr, u32 name_ptr}` at **VA 0x007368E0 / RVA 0x003368E0** in
`d1a.exe`, the Ringwide build of Sega Racing Classic (x86-32, MSVC 9.0, TimeDateStamp
`0x4B0F667E` = 2009-11-27, ImageBase 0x400000, relocs stripped). Monotonic in guest address,
`start_ip` at 0x860 through `FlagFreeplay` at 0x5FE040. See [d1a-ringwide-recon.md](d1a-ringwide-recon.md)
for what that binary is and why it matters; see [m2-rom-symbol-tables.md](m2-rom-symbol-tables.md)
for the same table in the five x64 pxd modules and the cross-game name map.

Guest layout matches every other Model 2 ROM here: program ROM from 0, work RAM at 0x5xxxxx,
backup/EEPROM shadow at 0x5FExxx. **Do not filter by address when extracting** - the RAM
globals are most of what netplay work needs (the same trap [von-rom-symbols.md](von-rom-symbols.md) records).
