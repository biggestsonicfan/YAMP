# Virtual On ROM symbols

Extracted from the PS3 build's own symbol table (`EBOOT.elf` @ **0x00441070**, 276 records of
`{u32 guest_addr, u32 name_ptr}`, big-endian). The same table exists in the PC module at RVA
**0x4507E0** with 16-byte `{u64, u64}` records.

**Extract it with NO address filter.** An earlier pass here filtered to `addr < 0x200000` on the
assumption the table named code, and so silently dropped every RAM global - which is most of what
netplay needs (`GlobCntr`, `net_flag`, `link_ID`, `MainMode`, `SubMode`). Guest RAM is at 0x5xxxxx
and the I/O boards at 0x1Axxxxx.
